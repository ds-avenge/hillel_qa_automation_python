The main goal of this repository is to document my progress in Python and build practical skills required for automated software testing.

---

## About the Course

The course covers Python programming from the fundamentals to building and running automated tests for APIs and web applications.

The learning path includes:

- Python fundamentals
- Object-Oriented Programming
- Git and GitHub
- Exception handling and logging
- File processing
- Unit testing
- API automation
- Database testing
- Pytest
- Playwright
- Docker
- Test reporting
- CI/CD with Jenkins
